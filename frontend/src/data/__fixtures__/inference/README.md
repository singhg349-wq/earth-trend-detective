# Inference fixtures

Fixture-only result documents for the `trend.inference` block. They let the result
card and its tests cover the agreed fields before real artifacts carry them:
`status`, `p_value`, `ci`, `method`, `strict_check_pass`, `strict_check_p`, `lag1`,
`caution`, `ci_note` and `n`.

These values are fake and are not climate results. They are not copied into
`public/data` and do not appear in the app; `data/fixtures` remains the app's
placeholder series set.
