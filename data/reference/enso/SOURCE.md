Source note: CPC Oceanic Niño Index (ONI), January values, copied from the NOAA PSL oni.data snapshot supplied with the project inputs. Each January entry is the centered December–February three-month running mean. Only years 1984–2025 are included; source missing sentinel values are not retained as observations. Units are degrees Celsius anomaly. The upstream footer describes ONI based on ERSST V6 in Niño 3.4; values are used as supplied for this predeclared association.
