# Short Project Summary (<= 200 words)

TrendTrace
Click anywhere on Earth. See what's changing — and how sure we are.

TrendTrace is an interactive 3D globe where anyone can click a place and see how seasonal rainfall, temperature, aerosol haze, or topsoil moisture has changed since 1980—with the statistical checks right beside the number. Clicking any location snaps to a 1° cell and computes Sen's slope per decade, a 95% confidence interval, an autocorrelation-corrected Mann–Kendall p-value (Hamed–Rao, 3 lags), and a prewhitened Yue–Wang sensitivity check directly in the browser. Ten named regions also offer Dec–Feb series and 20 global seasonal anomaly timelapses across all four variables. An El Niño atlas pairs 921 NOAA RONI seasons (`1950–2026`), 574 monthly ERSST v6 sea-surface temperature anomaly frames (`1979–2026`), a 12-month normal-year climatology (`1991–2020`), and six detrended El Niño minus La Niña composite impact maps with false-discovery-rate hatching (`q = 0.10`). Method check: our processing pipeline reproduced NASA Giovanni's results for two test regions (Coastal Peru and Indonesia rainfall, Dec–Feb). Every other series is produced by the same code but has not been compared individually.
